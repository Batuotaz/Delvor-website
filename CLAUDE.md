# Delvor website

Delvor is an English-first Local SEO and Google Maps visibility services website for international B2B audiences.

## Product direction

The site explains local visibility, Google Maps measurement, local SEO foundations, rank tracking and a request-based seven-day trial. English is the primary locale. Latvian, Estonian, Finnish and Swedish are planned for the localization architecture.

## Content rules

- Use DELVOR branding and original content.
- Mark illustrative ranking data clearly.
- Use approved client results and testimonials only.
- Do not promise a Google ranking position or invent pricing.
- Do not create About Us, Team or Contacts pages.
- Trial submissions remain requests until the server integration is enabled.

## Technical direction

- Keep all provider keys server-side.
- Validate trial payloads on the server.
- Keep n8n and future LlamaMaps communication behind server route handlers.
- Preserve the repository and current deployment infrastructure.
